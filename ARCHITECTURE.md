> Generated by /map on 2026-08-25

## Overview
**Dark Trace AI** is a dual-tier AI threat intelligence and behavioral communication analysis platform designed to detect illicit drug-trafficking patterns, encoded slang, emoji symbolism, and network syndicates across social messaging channels (Telegram, Signal, Discord, WhatsApp).

The system integrates high-throughput sub-millisecond machine learning inference (XGBoost + feature engineering), explainable AI (SHAP TreeExplainer), semantic vector retrieval (ChromaDB + SentenceTransformers), and graph network analysis (NetworkX PageRank & Degree Centrality).

## Components

### 1. Web Frontend (`frontend/index.html`)
- **Purpose:** High-tech cyber intelligence user interface. Provides real-time risk gauges, SHAP attribution visualizers, D3.js interactive force-directed graph diagrams, and live telemetry feeds.
- **Location:** `frontend/index.html`
- **Dependencies:** D3.js (v7), TailwindCSS (CDN), Google Material Symbols & Fonts.
- **Hosting:** Vercel Static Hosting (`frontend/vercel.json`).

### 2. FastAPI Core Engine (`api/main.py`)
- **Purpose:** REST microservice exposing predictive inference, explainability, vector similarity retrieval, and ego-network generation.
- **Location:** `api/main.py`
- **Key Endpoints:**
  - `POST /predict`: Real-time risk probability (High/Med/Low) + SHAP local attributions.
  - `POST /batch_predict`: High-throughput multi-message evaluation.
  - `POST /semantic_search`: RAG semantic similarity queries against historical intercepts.
  - `POST /network_analysis`: Ego-network graph construction and PageRank centrality scoring.
  - `GET /health`: Microservice readiness & model status.
  - `GET /benchmark`: On-demand 100-run inference latency benchmarking.
- **Dependencies:** `create_final_model.py`, `artifacts/xgboost_pipeline.joblib`, `drug_emoji_dictionary.csv`, `drug_slang_dictionary.csv`.

### 3. Feature Extraction Subsystem (`create_final_model.py`)
- **Purpose:** Domain-specific NLP preprocessing pipeline. Extracts slang density, emoji frequency, price cues (`$`, `cash`, `usd`), urgency keywords, and location patterns.
- **Location:** `create_final_model.py`

### 4. Vector Retrieval & Ingestion (`ingest.py` & `chroma_data/`)
- **Purpose:** Generates semantic embeddings with `all-MiniLM-L6-v2` and persists indexed intercepts in a persistent ChromaDB database.
- **Location:** `ingest.py`

### 5. Streamlit Intelligence Hub (`streamlit_app.py`)
- **Purpose:** Alternative data science exploration dashboard for internal analysts.
- **Location:** `streamlit_app.py`

## Data Flow

1. **Client Intercept Ingestion:** Client inputs intercepted communication via UI or API payload (`MessageInput`).
2. **Feature Engineering:** `create_final_features()` maps text into structured lexical and heuristic signals.
3. **Inference Execution:** `xgboost_pipeline.predict_proba()` calculates threat probability in `< 1.0 ms`.
4. **Attribution & Explanation:** `shap.TreeExplainer` maps feature contributions to prediction delta.
5. **Semantic Enrichment:** ChromaDB retrieves nearest top-K historical threats for contextual corroboration.
6. **Network Correlation:** Graph engine maps communication nodes and outputs PageRank centrality metrics.

## Conventions

- **Naming:** Snake_case for Python modules and variables; kebab-case for deployment workflows and files.
- **Error Handling:** Graceful model/database fallbacks in `api/main.py` with descriptive HTTP status codes (e.g. 503 if vector store offline).
- **Environment Decoupling:** Strict 12-factor adherence via `.env.example` and dynamic runtime fallback detection.
- **Testing:** Automated Pytest suite (`test_api.py`, `test_latency.py`) with strict sub-millisecond assertions.
